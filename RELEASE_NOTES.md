# ConvErtaLocAA 0.2.0

Download **ConvErtaLocAA-windows-x64.zip**, extract the entire folder, and run **ConvErtaLocAA.exe**. Windows 10/11 x64; no separate Python installation is needed.

- Local image conversion, including HEIC input.
- Photos to PDF and PDF merging with a reorderable page queue.
- Page previews, rotation, duplication, and PDF-to-image export.
- Results saved to the ConvErtaLocAA folder on your Desktop.
- No accounts, uploads, telemetry, or automatic updater.

HEIC output is not included. This release is not code-signed.

The Windows build runs conversion tests against generated images/PDFs and a public HEIC fixture, plus an interface self-test. Test files are excluded from the downloads.

**ConvErtaLocAA-decoder-sources.zip** contains upstream HEIC decoder sources, build recipes, and notices. **SHA256SUMS.txt** provides download checksums.
